# Visual credits

The cat, the fur, the eyes, and the whiskers are original geometry
and shaders written for this game. There is no downloaded model.

- `visual/fur.gdshader` — shell fur, written here.
- `visual/cat_fidelity.gd` — shells, cornea, pupil, catchlight, whiskers.
- Coat colours stay Daniel's ruled spec in `cat_kit/cat_species.json`
  (Willie white and `#E8AF54` ginger, dark eyes; Aggie's calico).
- No CC-BY assets are bundled, so there is no attribution line to add.
  If a later pass brings in a CC-BY or CC0 mesh, name the author here.
