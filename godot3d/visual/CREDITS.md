# Visual credits

The eye rig and the whisker strands are original work for this game.
Both cats' visible bodies are generated meshes.

- Willie was generated with Hunyuan3D v3.1 Pro through Fal, on Daniel's
  account, from the Willie reference views. The 18 MB source mesh is
  not in the repo. `tools/fit_willie_hunyuan.py` straightens the head,
  skins the surface to the existing cat skeleton, and writes the two
  LODs below. The meow clip still keys the bone named `jaw`.
- `cat_kit/meshes/willie_lod0.glb` — desktop Willie, about 32k
  triangles and a 2048 albedo. Kept out of the web export.
- `cat_kit/meshes/willie_lod2.glb` — web Willie, about 12k triangles
  and a 1024 albedo.
- Aggie was generated the same way, from her reference photos, on the
  same Fal account. The 25 MB source mesh is not in the repo.
  `tools/fit_aggie_hunyuan.py` skins the provided 40k mesh, darkens and
  warms the albedo toward `#241C17`, `#B06E2C` and `#BFA87A`, tints the
  chest blaze to cream and orange, and paints out the light fleck under
  her chin. She stays at scale 0.25.
- `cat_kit/meshes/aggie_lod0.glb` — desktop Aggie, 40k triangles and a
  2048 albedo. Kept out of the web export.
- `cat_kit/meshes/aggie_lod2.glb` — web Aggie, 12k triangles and a
  1024 albedo.
- `tools/build_cat.py` — the skeleton both cats share. Built in Blender
  4.2 from cross-sections (skull, muzzle, chest, waist, haunch,
  digitigrade legs, toes, ears, tapered tail), fused with a voxel
  remesh and quadriflow, then subdivided. The armature, the clips
  (idle, walk, trot, sprint, stalk, pounce, land, swipe, meow, sit,
  lounge), and the procedural maps are generated by that script.
  Nothing in it is traced from a third-party mesh.
- `cat_kit/meshes/cat.glb` — the shared skeleton and the 11 clips.
- `cat_kit/meshes/willie_albedo.png`, `aggie_albedo.png`,
  `cat_normal.png`, `cat_roughness.png` — maps from the same script.
  Willie's ginger is `#E8AF54`. Aggie's patches are her palette.
  The visible Hunyuan coats use their own baked albedos.
- `visual/fur.gdshader` — shell fur, written here, skinned to the
  same skeleton as the body.
- `visual/cat_fidelity.gd` — shells, cornea, pupil, catchlight, whiskers.
- Coat colours stay Daniel's ruled spec in `cat_kit/cat_species.json`.
- No CC-BY assets are bundled, so there is no attribution line to add.
